# API pública de contratos

| Archivo o subcarpeta | Propósito |
|---|---|
| `index.ts` | Punto de entrada de las exportaciones del paquete. |
| `modules.ts` | Catálogo de módulos funcionales. |
| `navigation.ts` | Contratos de navegación y estructura de menús. |
| `permissions.ts` | Permisos compartidos entre backend y frontend. |
| `roles.ts` | Roles y capacidades asociadas. |
| `schemas/` | Esquemas de validación para datos intercambiados por la aplicación. |
