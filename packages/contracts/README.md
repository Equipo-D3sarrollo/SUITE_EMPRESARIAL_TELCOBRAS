# Contratos compartidos

Paquete `@telcobras/contracts`: publica tipos, constantes y esquemas usados para mantener alineados API y frontend.

| Archivo o subcarpeta | Propósito |
|---|---|
| `package.json` | Metadatos, dependencias y comandos del paquete. |
| `tsconfig.json` y `tsconfig.build.json` | Configuración TypeScript y compilación publicada. |
| `src/` | Implementación de contratos, catálogos y validaciones compartidas. |
| `openapi/` | Especificación OpenAPI exportada. |
| `test/` | Pruebas de catálogos, NIT y esquemas. |
