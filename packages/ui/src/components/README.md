# Componentes reutilizables

Cada archivo implementa un control o patrón visual para componer pantallas del producto.

| Archivo | Propósito |
|---|---|
| `accordion.tsx` | Secciones desplegables. |
| `avatar.tsx` | Representación visual de una persona o cuenta. |
| `badge.tsx` | Etiquetas compactas. |
| `button.tsx` | Botones y variantes de acción. |
| `card.tsx` | Contenedores de contenido. |
| `data-table.tsx` | Presentación tabular de registros. |
| `dialog.tsx` | Ventanas modales. |
| `dropdown-menu.tsx` | Menús desplegables de acciones. |
| `empty-state.tsx` | Estado sin datos con mensaje o acción. |
| `field.tsx` | Estructura común de campos de formulario. |
| `input.tsx` | Control de entrada de texto. |
| `kpi-card.tsx` | Tarjeta para mostrar indicadores clave. |
| `label.tsx` | Etiquetas accesibles para controles. |
| `popover.tsx` | Contenido contextual emergente. |
| `scroll-area.tsx` | Región con desplazamiento estilizado. |
| `select.tsx` | Selector de opciones. |
| `separator.tsx` | Separadores visuales. |
| `skeleton.tsx` | Marcadores de carga. |
| `status-badge.tsx` | Etiquetas visuales de estado. |
| `switch.tsx` | Control booleano de activación. |
| `tabs.tsx` | Navegación entre paneles de una vista. |
| `tooltip.tsx` | Ayuda breve contextual. |
