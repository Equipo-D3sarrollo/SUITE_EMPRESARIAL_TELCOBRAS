# Código fuente de la biblioteca UI

| Archivo o subcarpeta | Propósito |
|---|---|
| `index.ts` | Punto de entrada que expone los componentes de la biblioteca. |
| `components/` | Componentes visuales de uso común. |
| `lib/` | Funciones auxiliares para clases y estilos. |
| `styles/` | Tokens y estilos globales del tema. |
