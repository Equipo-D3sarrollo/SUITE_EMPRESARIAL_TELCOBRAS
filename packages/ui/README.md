# Biblioteca de interfaz

Paquete `@telcobras/ui`: componentes y estilos visuales reutilizables por las aplicaciones del monorepo.

| Archivo o subcarpeta | Propósito |
|---|---|
| `package.json` | Metadatos, dependencias y scripts de la biblioteca. |
| `tsconfig.json` | Configuración TypeScript del paquete. |
| `vitest.config.ts` | Configuración de Vitest para sus pruebas. |
| `src/` | Exportaciones, componentes y recursos visuales. |
| `test/` | Pruebas de comportamiento y renderizado de componentes. |
