# API de la suite

Aplicación backend NestJS responsable de exponer los endpoints, autenticar usuarios y coordinar persistencia y módulos del producto.

| Archivo o subcarpeta | Propósito |
|---|---|
| `package.json` | Dependencias y comandos de desarrollo, pruebas, compilación y migraciones de la API. |
| `nest-cli.json` | Configuración del CLI de NestJS. |
| `drizzle.config.ts` | Configuración de Drizzle Kit para el esquema y las migraciones. |
| `tsconfig.json` y `tsconfig.build.json` | Opciones TypeScript para desarrollo y compilación. |
| `vitest.config.ts` | Configuración de Vitest para la API. |
| `src/` | Módulos, configuración, entrada HTTP, base de datos y contratos de API. |
| `test/` | Pruebas de API y utilidades de integración. |
