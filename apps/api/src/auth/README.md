# Autenticación de API

| Archivo | Propósito |
|---|---|
| `auth.module.ts` | Integra el módulo de autenticación con NestJS. |
| `permissions.ts` | Exige un permiso del usuario dentro de la transacción de la organización. |
| `session.guard.ts` | Protege endpoints que requieren una sesión autenticada. |
