# Módulos funcionales de la API

Cada subcarpeta agrupa el controlador, servicio y módulo NestJS de una capacidad delimitada.

| Subcarpeta | Propósito |
|---|---|
| `documents/` | DataDian: facturas recibidas de la DIAN, su decisión e historial. |
| `health/` | Endpoint y servicio de estado de la API. |
| `invitations/` | Operaciones de invitación a organizaciones. |
| `organizations/` | Operaciones y lógica de organizaciones. |
