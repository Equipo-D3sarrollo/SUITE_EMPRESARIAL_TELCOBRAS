# Código fuente web

| Archivo o subcarpeta | Propósito |
|---|---|
| `main.tsx` | Punto de entrada del cliente React. |
| `styles.css` | Estilos globales y base visual de la aplicación. |
| `vite-env.d.ts` | Tipos de entorno de Vite para TypeScript. |
| `app/` | Router, providers y estados de navegación. |
| `features/` | Flujos y capacidades de producto, como autenticación y onboarding. |
| `i18n/` | Textos y configuración de idioma. |
| `lib/` | Cliente de API, autenticación, consultas y utilidades. |
| `shell/` | Estructura persistente de la interfaz y zonas de navegación. |
