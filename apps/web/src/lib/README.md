# Clientes y utilidades web

| Archivo | Propósito |
|---|---|
| `api-client.ts` | Cliente HTTP tipado para consumir la API. |
| `api-schema.ts` | Tipos del esquema de la API usados por la interfaz. |
| `auth-client.ts` | Cliente del proveedor de autenticación. |
| `format-co.ts` | Formatea valores de acuerdo con convenciones de Colombia. |
| `queries.ts` | Definiciones de consultas de datos de la aplicación. |
| `query-client.ts` | Configuración del cliente de consultas/caché. |
| `use-debounced-value.ts` | Hook para diferir cambios rápidos de valor. |
