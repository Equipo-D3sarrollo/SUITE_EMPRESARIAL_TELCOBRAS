# Funcionalidades de producto

Las capacidades visibles de la aplicación se mantienen agrupadas por flujo o estado.

| Subcarpeta | Propósito |
|---|---|
| `auth/` | Registro, acceso por código, autenticación externa e invitaciones. |
| `onboarding/` | Configuración inicial posterior al registro. |
| `module-placeholder/` | Vistas temporales para módulos cuya funcionalidad aún no está implementada. |
