# Autenticación e invitaciones

| Archivo | Propósito |
|---|---|
| `auth-layout.tsx` | Layout compartido para páginas de autenticación. |
| `form-error.tsx` | Presenta errores de formularios. |
| `google-sign-in.tsx` | Acción de inicio de sesión con Google. |
| `invitation-page.tsx` | Interfaz para aceptar o resolver invitaciones. |
| `login-page.tsx` | Flujo de inicio de sesión. |
| `otp-step.tsx` | Paso para introducir el código de un solo uso enviado por correo. |
| `register-page.tsx` | Flujo de registro. |
| `totp-step.tsx` | Paso de verificación con TOTP. |
| `use-enter-app.ts` | Hook que dirige al usuario al espacio de trabajo después del acceso. |
