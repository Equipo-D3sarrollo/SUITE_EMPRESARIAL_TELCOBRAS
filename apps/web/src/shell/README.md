# Shell de la aplicación

Contiene la interfaz persistente alrededor de las páginas del espacio de trabajo.

| Archivo o subcarpeta | Propósito |
|---|---|
| `app-shell.tsx` | Ensambla el shell principal. |
| `module-icons.ts` | Asocia iconos con módulos de navegación. |
| `navigation.ts` | Construye la navegación del shell. |
| `no-modules-view.tsx` | Estado vacío cuando no hay módulos disponibles. |
| `shell-skeleton.tsx` | Esqueleto de carga del shell. |
| `zone0-topbar/` | Barra superior, acciones globales y selector de organización. |
| `zone1-sidebar/` | Navegación lateral. |
| `zone2-workspace/` | Área de trabajo central. |
| `zone3-context/` | Panel de contexto complementario. |
| `zone4-status/` | Estado y conectores del sistema. |
