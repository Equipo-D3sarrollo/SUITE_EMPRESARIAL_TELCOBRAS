# Componente InteractiveBackground

| Archivo | Propósito |
|---|---|
| `InteractiveBackground.jsx` | Componente React que renderiza e integra el fondo interactivo en una vista. |
| `engine.js` | Motor de ejecución que coordina la actualización y el renderizado de los efectos. |
| `effects.js` | Implementaciones/configuración de los efectos visuales disponibles. |
| `index.js` | Punto de entrada del componente y sus exportaciones. |
| `InteractiveBackground.test.jsx` | Pruebas del componente de fondo interactivo. |
