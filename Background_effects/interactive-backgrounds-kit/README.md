# Kit de fondos interactivos

Este kit reúne ejemplos y código de efectos visuales de fondo; no está incluido entre los paquetes del workspace pnpm.

| Archivo o subcarpeta | Propósito |
|---|---|
| `CLAUDE.snippet.md` | Fragmento de instrucciones de trabajo relacionado con el kit. |
| `copilot-instructions.snippet.md` | Fragmento de instrucciones para asistentes de desarrollo. |
| `docs/` | Catálogo y demostraciones de efectos. |
| `src/` | Implementación reutilizable del fondo interactivo y sus pruebas. |
