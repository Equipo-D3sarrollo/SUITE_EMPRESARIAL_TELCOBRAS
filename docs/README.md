# Documentación del proyecto

La documentación de alcance y ejecución se complementa con las carpetas especializadas:

| Elemento | Propósito |
|---|---|
| `DOCUMENTO_MADRE_SUITE_TELCOBRAS.md` | Fuente rectora de alcance y definición del producto. |
| `PLAN_IMPLEMENTACION_INICIAL.md` | Plan de etapas para construir la suite. |
| `PENDIENTES.md` | Decisiones diferidas e información aún por resolver. |
| `Arquitectura/` | Material técnico de arquitectura, diseño y frontend. |
| `decisions/` | Registro de decisiones de arquitectura (ADR). |
| `etapas/` | Especificaciones de alcance para etapas posteriores. |
