# APIDIAN (FacturaLatam)

Herramienta que se evalúa para que DataDian (módulo 04, antes «Documentos») descargue de la DIAN los documentos
electrónicos recibidos, antes de pasarlos a aprobación y a Odoo.

**Empiece por `ANALISIS_APIDIAN.md`.** Resume qué es APIDIAN, cómo funciona su Extractor V2, qué
exige cada operación, cómo encaja en la suite, los riesgos y las preguntas abiertas.

| Elemento | Contenido |
|---|---|
| `ANALISIS_APIDIAN.md` | Análisis para el módulo 04 |
| `repositorio-original/` | Destino del clon del código original de APIDIAN y su extractor, con el script para clonarlo. El código clonado no se versiona |
| `referencia/` | Copia íntegra de la documentación pública, descargada el 10-nov-2026: manual oficial (290 páginas), colección Postman (185 requests), índice de endpoints y transcripción del video del extractor |

`referencia/` es material de terceros y de solo lectura. No se edita a mano: si FacturaLatam
publica cambios, se vuelve a descargar completa. Sus ejemplos traen razones sociales y nombres
reales: no se usan como datos de prueba.
